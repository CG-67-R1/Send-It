- **Avatar face-capture rework — RESOLVED.** The multi-bug capture failure (Android `skipProcessing` + wrong crop math + full-screen CameraView misalignment) is now fixed by:

- **[P2]** `CAPTURE_PREVIEW_SCALE = 0.42` is hardcoded. This value determines the arm's-length framing. A future per-avatar override mechanism exists (`FACE_HOLE_LAYOUT_OVERRIDES` is populated; could add a `capturePreviewScale` override) but isn't wired yet. Low priority.
