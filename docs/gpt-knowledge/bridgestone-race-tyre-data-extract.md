## 2. RACING BATTLAX V03 (non-DOT, track use only)

**Positioning:** Latest generation race slick (successor line to V02 in the databook narrative); **track use only**; contact distributor (e.g. **1-800-828-9143** in source for US race dealer locator).

**Marketing / tech claims (source):** New compounds including Bridgestone’s first **Sprint** rear compound; optimised profile vs V02; claimed **~1.9% faster dry lap** in cited internal test (V03F Soft / V03R Sprint vs V02F NS-Soft / V02R NS-Soft, one lap session — *results vary*).

## 4. RACING BATTLAX W01 (wet, non-DOT)
