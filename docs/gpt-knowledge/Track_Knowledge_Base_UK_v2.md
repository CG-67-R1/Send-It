# Track Knowledge Base — United Kingdom v2

Coaching bias and venue notes for UK road circuits. **Geometry authority:** `track_geometry_uk.json`. Do not invent turn hands from this prose.

## Brands Hatch (GP / Indy)

- Signature: Paddock Hill Bend commitment; Druids hairpin; GP woodland section (Sheene / Stirling's).
- Confirm Indy vs GP before corner coaching.
- Common rider themes: early brake release into Paddock, patience at Druids, sighting for Sheene.

## Donington Park (National / GP)

- Signature: Craner Curves downhill left; Old Hairpin setup from Craner exit; McLean's off-camber.
- National ends via Roberts; GP uses Fogarty Esses → Melbourne Hairpin → Goddards.
- Build Craner speed gradually; lifting mid-corner unsettles the bike.

## Silverstone (National focus)

- High average speed; Copse / Maggotts–Becketts load; Brooklands–Luffield–Woodcote finish.
- Wind and tyre heat matter on long sessions.
- Ask which layout (National / International / GP).

## Snetterton 300

- Heavy braking into Riches / Montreal; long Bentley Straight; Coram–Murrays for drive onto Senna Straight.
- Good for braking and drive-exit coaching drills.

## Cadwell Park

- Narrow parkland; Charlies double-apex; The Mountain crest (wheelie / loft risk).
- Prefer caution and complex labelling until layout-confirmed turn list is locked with the rider.

## Oulton Park / Thruxton / Knockhill

- Oulton: elevation, trees, Knickerbrook history — confidence and sight lines.
- Thruxton: very fast; Club chicane is a major event.
- Knockhill: compact Scottish venue; SACU context for local racing.

## Licensing context (coaching, not legal advice)

- Track days: operator briefing; no ACU race licence required.
- Club racing: ACU CTC + BRA → Novice → Clubman → National (England/Wales); SACU / MCUI elsewhere.
- Always defer to current ACU Standing Regulations / event regs for licence grades.
