## What “enterprise-approvable” means here

Treat as **approvable** only with evidence of at least one of:

- SOC 2 Type II / ISO 27001 on a trust center
- FedRAMP Marketplace listing **or** GovCloud/Azure Government/Vertex Assured Workloads path
- Admin controls: SSO/SCIM, DPA, no-training / data residency, model allow/deny
- GitHub Copilot Business/Enterprise or Cursor Teams/Enterprise admin policy

A Twitter demo, lmsys rank, or “Mythos-class” label is not approval.
